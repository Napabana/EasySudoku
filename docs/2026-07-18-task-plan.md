### 生产部署风险

- `frontend/dist` 缺失时默认静默回退旧 HTML，可能掩盖失败构建；
- SPA catch-all 会把未知 API 路径返回成 HTML；
- `/upload` 没有 MIME、空文件和大小限制，也没有结构化 OCR 错误；
- 缺少健康与版本端点，容器无法区分进程存活和前端/OCR 资源就绪；
- Docker 使用 `npm install`，且没有 `HEALTHCHECK`；
- 没有 CI；当前 WSL 的默认 `npm` shim 与 Linux Node 不兼容，验证必须使用仓库安全脚本或干净 CI。
